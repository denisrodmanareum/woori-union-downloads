## 기존에 앱을 설치했다면

**설치 오류를 해결하려고 기존 앱을 삭제하지 마세요.**
현재 테스트 APK는 이전 기준 APK와 서명이 다릅니다. 앱 삭제 시 기기에 저장된 상담 접근 정보가 유실될 수 있습니다. 기존 설치 업데이트는 같은 서명키가 필요하므로 별도 테스트 기기에 먼저 설치하세요.

## 다운로드 파일 확인

파일의 SHA-256은 각 릴리스의 `SHA256SUMS.txt`에서 확인할 수 있습니다.
다운로드 링크 공개는 앱 내부의 회원 승인이나 기능별 권한을 부여하지 않습니다.
